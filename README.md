# Sales & Customer Analysis Dashboard

## Описание проекта

Power BI-проект для анализа продаж и клиентских показателей.

## Инструменты

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Задачи проекта

- Анализ продаж
- Анализ клиентской базы
- Сравнение показателей по категориям и сегментам
- Анализ динамики показателей
- Расчет ключевых KPI
- Создание интерактивных фильтров
- Визуализация результатов анализа

## Использованные инструменты

- Power Query
- DAX
- Relationships
- KPI
- Filters
- Charts
- Interactive Dashboard

## Результат

Дашборд позволяет анализировать продажи и клиентские показатели, отслеживать динамику и сравнивать результаты по различным сегментам.
